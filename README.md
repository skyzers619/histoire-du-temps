# L'HISTOIRE DU TEMPS — V2 vérifiée

Cette V2 privilégie la vérifiabilité : les événements affichés sont reliés à des pages officielles Rolex, Patek Philippe, OMEGA, Cartier ou TUDOR lorsque la source a été identifiée.

IMPORTANT : aucune photographie tierce n'est intégrée comme si elle était officielle. Les blocs d'archives renvoient vers les pages officielles. Avant publication, vérifier les droits de réutilisation de toute image.

La V2 retire volontairement certaines dates ou caractéristiques génériques lorsqu'elles ne sont pas suffisamment vérifiées.

Fichiers : index.html, style.css, app.js.
